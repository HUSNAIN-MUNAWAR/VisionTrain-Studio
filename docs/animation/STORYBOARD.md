# VisionTrain training reel storyboard

| Scene | Visual cue | Evidence shown | Gate |
| --- | --- | --- | --- |
| 01 · dataset | Bright/dark image tiles enter | Image count and class count | Dataset path is explicit |
| 02 · validate | Train/val folders turn green | Split counts and class consistency | Invalid structure blocks launch |
| 03 · profile | Hardware signal card appears | Device mode and package readiness | Runtime capability is visible |
| 04 · model | ResNet18 registry card activates | Trainer, format, precision, dependency | Compatibility reason is explicit |
| 05 · train | Launch gate opens or holds | Enabled flag and missing dependency | No fabricated metrics |
| 06 · export | Downstream artifact station waits | Checkpoint requirement and export formats | Export follows a real run |
